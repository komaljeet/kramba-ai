Token Embedding — Standard nn.Embedding layer. Maps each token ID to a dense vector in ℝd_model. This is the same as in a Transformer.
VortexInjectionLayer — Each token embedding is projected into a vorticity vector ωt = Wω · xt. The Biot-Savart law computes velocity: vt = Γ · (H · ωt). This is a single matrix-vector product — O(d²), constant in N. The token's representation is deflected: r̃t = xt + gt ⊙ vt where gt is a learned gate.
HamiltonianMemoryBlock — A fixed d×d matrix that evolves via quantum entanglement renormalization: H ← (1-η)·H + η·(Pt - H·Pt·H). The Pt = vt ⊗ vtT term is the interaction projector (rank-1). SVD truncation to rank-r discards noise modes. This is deterministic — no gradient descent at inference.
HVNBlock — Wraps vortex injection + Hamiltonian update + FFN in a parallel residual: x = x + vortex(norm(x)) + ffn(norm(x)). Uses RMSNorm (like LLaMA). Supports multi-head (parallel H matrices), multi-thread (K H per head), chunked parallel processing, and all quality strategies.
HVNDecoder — A shallow linear projection from d_model to vocab_size. Optionally includes a small MLP. The decoder probes the final hidden state to produce vocabulary logits.

Theoretical Framework

The mathematical formalism behind HVN.

🌊 Lagrangian Vortex Particle Mapping

Each token embedding x_t ∈ ℝ^d is interpreted as a Lagrangian vortex particle with:

  • Position: rt — the token's embedding vector
  • Vorticity: ωt = Wω · xt — learned projection
  • Velocity: vt = Γ · (H · ωt) — Biot-Savart local approximation

The classical Biot-Savart law is a global O(N) integral. HVN replaces it with a local, fixed-size approximation: a single matrix-vector product against the Hamiltonian H — O(d²), constant in N.

⚛️ Quantum Entanglement Renormalization

The Hamiltonian H is a fixed d×d matrix that evolves via DMRG-style renormalization:

H_new = (1 - η) · H + η · (P_t - H · P_t · H)
  • Pt = vt ⊗ vtT — interaction projector (rank-1)
  • Destructive interference: H·Pt·H cancels already-aligned components
  • Associative alignment: Pt reinforces new associations
  • Renormalization: (1-η)·H preserves prior memory
  • SVD truncation: keep top-r singular values (discard noise)

This is a deterministic, single-pass update — no optimization step, no gradient descent. It runs in O(d²) time, independent of sequence length.

🔗 Why This Achieves Long-Range Recall

  • The Hamiltonian H is a compressed summary of all past tokens' vorticity — like a KV cache but in fixed O(d²) space
  • Entanglement renormalization ensures correlated concepts reinforce while noise cancels
  • The Biot-Savart local approximation means each token "feels" the entire history through H without scanning it
  • Analogous to how a fluid's velocity field at any point encodes the integrated effect of all upstream vortices
